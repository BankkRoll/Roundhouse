# Sources

Every endpoint, field, pagination scheme, rate-limit header, error format,
firewall model, tag or label limit, user data limit, and price field was
checked against each provider's official documentation on **2026-10-22**,
unless a row says otherwise. Where a provider publishes an OpenAPI document,
that document was read directly. Items the docs leave open are listed per
provider under "Not verifiable from the docs" and summarised in the README.

Changelog entries that shaped the code:
- [2026-10-12 Link headers deprecated](https://docs.hetzner.cloud/changelog#2026-10-12-link-header-deprecation): pagination reads `meta.pagination` only.
- [2026-09-08 `deprecated` field removed on 2026-11-02](https://docs.hetzner.cloud/changelog#2026-09-08-removing-the-deprecated-field): offers use `locations[].deprecation`; legacy fields are optional.
- [2026-04-30 `GET /<resource>/{id}/actions/{action_id}` deprecated](https://docs.hetzner.cloud/changelog#2026-04-30-deprecate-get-resource-action-endpoints): actions are polled with `GET /actions?id=`.
- [2026-07-01 Datacenters removed](https://docs.hetzner.cloud/changelog#2026-07-01-removing-datacenters): servers are created by `location`.
- [2026-04-22 Leading whitespace in SSH keys invalid](https://docs.hetzner.cloud/changelog#2026-04-22-ssh-key-validation): keys are sent normalised.

Not verifiable from the docs:
1. Whether the scope check precedes body validation, which the token probe
   (`POST /ssh_keys` with an empty body) relies on.
2. The IPv6 host address: the API returns the /64, and `<prefix>::1` is what
   Hetzner's images configure.

## cloud-init (all providers)
